### Core JavaScript Fundamentals
#### Interviewers will test your ability to write raw JavaScript without relying entirely on frameworks.
***Closures & Scope***: Be ready to explain closures and how they can be used for data encapsulation.
The Event Loop & Asynchronous JS: Understand the call stack, web APIs, the callback queue, and the microtask queue (promises).
this Keyword & Execution Context: Be able to explain how this is determined and how to manipulate it using call, apply, and bind.
Event Delegation: Explain how attaching event listeners to a parent element can optimize performance and handle dynamically generated DOM elements.

### Healthcare & Enterprise UI Standards
#### Healthcare platforms have strict requirements for how patients and staff access information.
***Web Accessibility (a11y)***: Be prepared to discuss semantic HTML (e.g., `<main>`, `<nav>`), ARIA labels, keyboard navigation, and color contrast.
***Data Security***: Understand how to prevent Cross-Site Scripting (XSS) by sanitizing user inputs and escaping HTML.
Performance Optimization: Be ready to talk about debouncing search inputs (e.g., for patient or provider directories) and lazy-loading components to keep applications fast.

### Frameworks & State Management (React/Vue/Angular)
#### If the role uses a frontend framework, ensure you know how they interface with JavaScript.
***React Hooks (if applicable)***: Understand component lifecycles and how to manage side effects with useEffect, including clearing up event listeners to prevent memory leaks.
***State Management***: Discuss when to use local state versus global state management (like Redux or the Context API).
